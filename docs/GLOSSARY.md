# Glossary

- **Capability:** Task-specific held-out performance under a declared evaluation; never a universal scalar.
- **Capability density:** Capability paired with or divided by an explicitly measured resource.
- **Cognitive state:** Persistent information the tested runtime can access and depends on.
- **Compute proxy:** Reproducible operation/token/time count used when direct compute or energy is unavailable.
- **Controlled variable:** Condition intended to remain equal across comparison arms.
- **Equal-resource comparison:** Test matched on relevant budgets except declared independent variables.
- **Experience efficiency:** Held-out capability gain per new observation consumed.
- **Intervention:** The isolated change being tested against a baseline.
- **Observation:** One declared unit of environmental/training input; its granularity must be stated.
- **Persistent byte:** Stored byte required across tasks/runs by the cognitive system.
- **Procedure:** Compact executable or interpretable structure that derives behavior, rather than an answer list.
- **Raw experience:** Original observations, transcripts, episodes, or equivalent lossless records.
- **Representation accountability:** Explicit semantics, loss, costs, provenance, update, utility, and replacement plan.
- **Research telemetry:** Diagnostics not available to the evaluated runtime and excluded from cognitive claims.
- **Storage plateau:** Predeclared fixed persistent-state budget maintained while task sequence and capability grow.
- **Temporary state:** Disposable memory/storage needed only during the current task/run.
